## 🧠 Engineering Case Studies

Inside this portfolio, I document my approach to solving critical bottlenecks in software engineering:

1. **Retail SaaS Architecture**: Decoupling monoliths to microservices using Node.js and RabbitMQ to handle Black Friday traffic spikes.
2. **Financial Dashboard Performance**: Rendering +5000 updates/second in real-time via WebSockets without blocking the main thread.
3. **DevOps & Infrastructure**: Automating the entire deployment lifecycle from hours to minutes using Docker and GitHub Actions.

## 🛠 Tech Stack Focus

- **Architecture & Backend:** Node.js, PostgreSQL, Microservices, Clean Architecture, SOLID principles.
- **Frontend Experience:** React/Preact, Tailwind CSS, State Management, Performance Optimization.
- **Infrastructure:** Docker, CI/CD (GitHub Actions), AWS Basics.

## 🚀 Running Locally

If you want to check the code behind this portfolio:

```bash
# Clone the repository
git clone https://github.com/Stalone628/WS.git

# Install dependencies (using pnpm)
pnpm install

# Start the development server
pnpm run dev
```
